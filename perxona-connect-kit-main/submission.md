## 1. 企画概要・売り

CG-ARTS「CGクリエイター検定 ベーシック」の模擬試験（20回・400問）に、Perxonaの3Dアバターを"学習コーチ"として組み込んだ学習アプリです。

### 売りポイント

**1. アバターに励まされながら、たくさん問題を解ける**
一人で黙々と問題集を解くのは挫折しやすい作業ですが、隣に3Dアバターがいて、正解すれば一緒に喜び、間違えれば優しく声をかけてくれます。「量をこなす」学習のハードルを下げることが狙いです。

**2. AIが解説・総評をその場で動的生成**
問題ごとの簡易解説はあらかじめ用意していますが、「アバターにもっと聞く」を押すと、Claude（Anthropic API）がその設問・正誤状況に応じて一段階踏み込んだ解説をその場で作り、アバターが声に出して話します。模擬試験終了後には、10分野の得点分布から弱点を分析した総評コメントも自動生成されます。定型のフィードバックでは拾えない、一人ひとりに合わせた振り返りができます。

**3. Japanese accent mode ── バグから生まれた遊び心**
開発中、英語UIで日本語専用の音声を使ってしまい「日本語なまりの英語」になってしまうというバグがありました。直した上で、あえて「なまりモード」としてトグルを追加し、ユーザーが好きな時に日本語なまりの発音を楽しめる機能に転用しました。失敗を消すのではなく、面白さとして残した機能です。

## 2. 使い方

1. トップ画面で **演習モード**（1問ずつ即採点・解説あり）か **本番モード**（60分タイマー・最後にまとめて採点）を選ぶ
2. 第1回〜第20回、またはランダム出題から選んで開始 → アバターが挨拶
3. 選択肢を選ぶと、アバターが正解／不正解に応じて一言＋モーションで反応
4. 「アバターにもっと聞く」でAIによる詳しい解説を聞ける
5. 全問終了後、結果画面でレーダーチャート（分野別到達度）とアバターによる総評を確認
6. 右下のアバターパネルから、**背景シーン**・**Japanese accent mode**・言語（日本語/English）を自由に切り替え可能

## 3. 使用技術

| レイヤー | 技術 |
|---|---|
| 3Dアバター描画・音声合成 | Perxona Connect Kit（`<sv-presenter>` Presenter SDK） |
| 対話・解説生成AI | Claude API（Anthropic, `claude-sonnet-5`） |
| バックエンド | Node.js / Express（ローカル開発）、Netlify Functions（本番） |
| ホスティング | Netlify（GitHub連携・push時自動デプロイ） |
| クイズエンジン | 素のHTML/JS（ビルド不要、300問バンクから20回分を決定的に生成） |

## 4. 今後の開発

- **シーン連動の口調変化**：選んでいる背景シーン（オフィス／屋外の学校など）によって、アバターのアドバイスの口調や内容を変える
- **音声・テキストでの質問対応**：受験者がその場でアバターに自由記述で質問し、音声入力にも対応する
- **カスタム問題のスプレッドシート実装**：スプレッドシートに問題を用意するだけで、任意の資格・科目の模擬試験に展開できるようにする
- **アバターの成長システム**：練習を重ねるほど自分のアバターが育っていく仕組み（見た目や振る舞いの変化）
- **対戦モード**：サーバー上で他ユーザーのアバターと対戦できるモード
  - タイムトライアル（速さを競う）
  - 多答（同じ問題に対する正答数・正答率を競う）
