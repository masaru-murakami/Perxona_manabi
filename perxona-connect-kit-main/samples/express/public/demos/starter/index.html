How it works

              
Initialize, then present

              

                The page preloads the configured target with a server-issued
                Connect token. Audio still needs one user gesture before speech.
              

            

            
const { connect_token } = await request("/api/connect-token");

await presenter.initialize(connect_token, {
  avatarId,
  sceneId,
  voiceId,
});

// Call from a user gesture before speaking.
await presenter.resumeAudioPlayback();
await presenter.present("Hello! It is great to meet you.");
