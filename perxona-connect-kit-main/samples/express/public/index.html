Perxona Connect Kit — Demos

Pick a demo to try. Each one shares the same backend API in server.mjs.

  • Basic — catalog selection, presenter initialization, and speech playback with preset and free-text inputs.
  • Starter — configurable defaults, motion preview, Motion Markup, and the smallest complete integration.
  • External LLM — generate a catalog-grounded script on the server, preview it, then explicitly run it in the Presenter.
  • Chatbot — create and manage a Connect chatbot (CRUD), hold a multi-turn conversation, and have every reply spoken aloud by sv-presenter.
